Latest milestone (R1690)

The New Game prologue decodes cleanly. Garbled frames came from a store guard (R518) that drops every 0x03 byte written at an address ending in 3. Map 4 copies the movie player byte by byte over memory the title menu used, so those bytes kept the menu's old values. That broke instructions such as jr ra and the player's VLC lookup tables (0x03F5 became 0x00F5, i.e. every negative long-code level). It was found by decoding the disc's STR frames offline (tools/strv2.py): frames 1-2 matched the runtime's MDEC input exactly, and frame 3 diverged at block 380 on exactly those values. R1690 exempts the module's block in state 1. The module now matches the attract copy byte for byte.
